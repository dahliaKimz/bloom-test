# Bloom acceptance test checklist

- [ ] Brand displays Bloom (not Bloom V3) and footer credit is correct.
- [ ] Social links with valid URLs open, blank links do not show.
- [ ] Create new profile with old starting weight and newer current weight.
- [ ] Dashboard total change is based on original start weight.
- [ ] Backdated log does not override latest current-weight reading.
- [ ] Add, edit, delete weights and notes; history remains sorted.
- [ ] Graph filter 7D/30D/3M/All, point trends and tooltip work.
- [ ] Weekly/monthly summary and milestones show expected values.
- [ ] Switching profiles shows independent records.
- [ ] Light, dark, and theme toggle render correctly.
- [ ] Export JSON, preview restore, cancel and confirmed restore.
- [ ] Data persists after closing/reopening same site in same browser.
- [ ] Mobile viewport and desktop layout are usable.
- [ ] Reminder only appears while app is open.
- [ ] Test with browsers on Android/iOS before promising commercial compatibility.

**Not yet implemented:** cloud Google Drive backup, installable PWA, encryption, purchase licensing, automated background notification, production security/privacy review.
